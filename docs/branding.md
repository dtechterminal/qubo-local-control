# Brand images

`custom_components/qubo_local/brand/` holds the QUBO wordmark as the integration icon, cropped from
QUBO's own logo and centred on a transparent square (256 px and 512 px). Home Assistant 2026.3 and
newer show it directly from the integration, also without internet access. See the
[Home Assistant announcement](https://contributors.home-assistant.io/blog/2026/02/24/brands-proxy-api/).

The QUBO name and logo belong to Hero Electronix. They identify the compatible products; this
community integration is independent of QUBO and Hero Electronix. Brand artwork is not covered by
this project's MIT code license.
